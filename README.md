# ハングル手帖

ハングルと会話を同時に学ぶ韓国語学習アプリです。

**🌐 公開ページ: https://issan9411-tech.github.io/hangul-techo/**(mainにプッシュすると自動デプロイされます)

- **文字**: 子音・母音・激音/濃音・複合母音の一覧。タップで発音再生、「覚えた」チェックで進捗管理
- **フレーズ**: 10カテゴリ173フレーズ(ドラマ定番セリフ3カテゴリ含む)。文字タップで「子音+母音+パッチム」に分解。🎤ボタンで発音判定(音声認識)
- **組み立て**: 部品を選んでハングル1文字を組み立てて発音確認
- **クイズ**: 文字の読み/聞き取り(単語)/聞き取り(会話)の3モード
- **TOPIK**: 全6級×22問=132問の練習問題(語彙・文法・聞き取り・読解)+級別頻出単語帳360語(音声・発音チェック・ハングル分解・検索つき)+単語テストモード(間違えた単語は自動で復習デッキへ)
- **復習**: 忘却曲線ベースの間隔反復(SRS)。フレーズとTOPIK単語360語を統合したデッキから毎日5件ずつ新規追加
- **会話練習**: オフラインのシナリオ会話(カフェ・道案内・買い物・自己紹介)+ 2〜3人の会話を聞くリスニング教材16本(話者ごとに声を切替・字幕3モード・内容チェックつき)+ ローカルAIフリートーク

音声(読み上げ・音声認識)はブラウザ内蔵機能を使うため、**Chrome または Edge を推奨**します。

## 起動方法

このフォルダでローカルサーバーを立てて開きます(Pythonが入っていればコマンド1つです)。

```bash
cd hangul-techo
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開いてください。

> `index.html` をダブルクリック(file://)でもほぼ動きますが、PWA機能とAI接続が制限されるためサーバー経由を推奨します。

## スマホアプリとして使う(PWA)

サーバー経由で開くと PWA としてインストールできます。

- **PC (Chrome/Edge)**: アドレスバー右端のインストールアイコン →「インストール」
- **Android**: メニュー →「ホーム画面に追加」
- **iPhone**: 共有ボタン →「ホーム画面に追加」

インストール後は一度読み込んだ内容がキャッシュされ、オフラインでも文字表・フレーズ・クイズ・復習が使えます(音声合成は端末の対応状況によります)。

※ スマホから使う場合は、PCのIPアドレス(例 `http://192.168.x.x:8000`)で同じWi-Fiからアクセスしてください。

## ローカルAIフリートーク(無料・Ollama)

「会話練習」タブの「🤖 ローカルAIフリートーク」は、無料のローカルAI実行環境 **Ollama** を使います。会話データはPCの外に送信されず、利用料もかかりません。

### セットアップ(初回のみ・約10分)

1. https://ollama.com からOllamaをインストール(Mac / Windows / Linux 対応)
2. ターミナル(コマンドプロンプト)で韓国語に強い無料モデルを取得:

   ```bash
   ollama pull exaone3.5:2.4b
   ```

   `exaone3.5:2.4b` はLG AI Researchの韓国語特化モデル(約1.6GB)。代わりに `qwen2.5:3b` などでも動きます。
3. Ollamaが起動していることを確認(通常はインストール後に自動起動。手動なら `ollama serve`)
4. アプリの「会話練習」→「🤖 ローカルAIフリートーク」→「接続テスト」

AIは「短い韓国語1文+カタカナ読み+日本語訳」の形式で返し、間違いがあれば日本語で直してくれます。🎤ボタンで音声入力もできます。

### つながらないとき

- `ollama serve` が起動しているか確認(ブラウザで http://localhost:11434 を開くと "Ollama is running" と表示されます)
- モデル名がアプリの入力欄と一致しているか確認(`ollama list` で確認できます)
- 別ポートでアプリを配信している場合にCORSエラーが出るときは、環境変数 `OLLAMA_ORIGINS="*"` を設定してOllamaを再起動してください
- **公開ページ(github.io)からローカルAIを使う場合**: Ollamaは標準ではlocalhost以外のページからの接続を拒否するため、環境変数 `OLLAMA_ORIGINS="https://issan9411-tech.github.io"` を設定してOllamaを再起動してください(Chrome/Edge推奨。SafariはHTTPSページからlocalhostへの接続をブロックします)

## アカウント同期(Firebase)のセットアップ

無料のFirebase(Google)を使って、ログインと学習記録のクラウド同期ができます。初回のみ約10分の設定が必要です。

1. https://console.firebase.google.com を開き、Googleアカウントでログイン →「プロジェクトを作成」(名前は自由。Googleアナリティクスは無効でOK)
2. 左メニュー「構築」→「Authentication」→「始める」→ ログイン方法で「**メール / パスワード**」を有効にして保存
3. 「構築」→「**Firestore Database**」→「データベースを作成」→ 本番環境モード → ロケーションは `asia-northeast1`(東京)推奨
4. Firestoreの「**ルール**」タブを開き、以下に置き換えて「公開」:

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

5. プロジェクトの設定(⚙)→「マイアプリ」→ ウェブ(`</>`)でアプリを追加 → 表示される `firebaseConfig = { apiKey: ... }` の `{ ... }` 部分をコピー
6. アプリのホーム →「👤 アカウント」→ 設定欄に貼り付けて「設定を保存」→ メールアドレスとパスワードで新規登録

これでログイン中は学習記録が自動的にクラウドへ保存され、別の端末でも同じアカウントでログインすれば記録を引き継げます。

> 補足: `firebaseConfig` は公開されても問題ない値です(セキュリティは手順4のルールで担保されます)。`index.html` の `FB_BUILTIN_CONFIG` にこのconfigを埋め込めば、端末ごとの貼り付けも不要になります。
